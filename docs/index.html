Połączenie z GitHubem

Żeby zapisać kierunki, strona potrzebuje tokenu GitHuba. Token zostaje tylko w tej przeglądarce.

  1. Otwórz github.com/settings/personal-access-tokens/new.
  2. Nazwa: dowolna, np. skaner-lotow. Wygaśnięcie: np. 1 rok.
  3. Repository access → Only select repositories → wybierz .
  4. Permissions → Contents: Read and write oraz Actions: Read and write.
  5. Generate token, skopiuj i wklej poniżej.
